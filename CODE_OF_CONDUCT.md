# Code of conduct

bms adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in every project space (issues, pull requests,
discussions and any chat the project runs) and when someone represents the project
elsewhere.

## Reporting

Report unacceptable behavior privately to the maintainers at
[conduct@zg3.net](mailto:conduct@zg3.net). Reports are handled in confidence, and the
enforcement guidelines of the Contributor Covenant 2.1 apply.
